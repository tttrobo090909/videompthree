# 영상엠피뜨뤼 (Video MP Three)

순수 오프라인 로컬 동영상 음원 추출 및 전용 플레이어 안드로이드 앱

## 핵심 기능
- **100% 온디바이스 오프라인**: 인터넷 권한 및 마이크 권한 0 (개인정보 유출 위험 제로)
- **1초 무손실 음원 추출**: 갤러리 영상 선택 후 [⚡ 추출] 원클릭으로 무손실 m4a 음원 추출
- **전용 플레이어**: 1곡/전체/랜덤 반복, 5초 앞뒤 탐색, 순백색 벡터 조작계
- **정갈한 음원 관리**: `Music/영상엠피뜨뤼` 전용 폴더 저장, `_1`, `_2` 순번제 파일명, 브라우저식 당겨서 새로고침, 체크박스 다중 삭제
- **전용 앱 아이콘**: 밝은 하늘색 격자무늬 바탕 + 순백색 MVmp3 타이포그래피 로고
